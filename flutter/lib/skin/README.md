# Skins

The documentation for this directory is **`flutter/SKINS.md`** — the skin
interface, the six facets, how to author a pack, the registry and its two
generated files, the disclosure gate, and the default-fidelity guarantees.

It used to live here. It moved for two reasons: it is read by people deciding
whether to *use* the app's skin system, not only by people editing this
directory; and it had grown a section describing device mechanism, which must
not sit in the tracked tree. That section is now
`packs_private/DEVICE-PACKS.md`, which is gitignored along with the packs it
describes.

Deep links are documented in `MACROS.md`, next to the booklet formats they
serve.
